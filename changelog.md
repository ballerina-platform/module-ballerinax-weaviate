# Change Log

This file contains all the notable changes done to the Ballerina Weaviate connector through the releases.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Client for the Weaviate REST API covering collections, objects, batch operations, search, GraphQL, tenants, aliases,
  backups, exports, replication, users, roles, groups and namespaces. All operations are remote methods.
- Two examples: `collection_data_management` and `access_role_setup`.
